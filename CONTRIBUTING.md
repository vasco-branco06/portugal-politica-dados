# Contribuir

1. Abre uma issue a descrever a fonte ou o problema.
2. Cria um ramo, faz as alterações e corre `pytest`.
3. Se adicionares uma fonte, preenche a linha em `docs/FONTES.md` com a licença. Sem licença confirmada, fica marcada como "por confirmar" e os dados não são republicados.
4. Não copies código nem conteúdo de outros repositórios. Liga-os em `fontes/` ou como dependência.
5. Não adiciones dados pessoais. Em jurisprudência, só texto já anonimizado na origem.
