# Licenças dos dados

O código deste repositório é MIT. Os dados não herdam essa licença.

Cada dataset publicado tem de indicar:

- a fonte original e o link;
- a licença da fonte;
- as transformações feitas;
- como citar.

Estado atual: nenhum dataset foi publicado. A tabela de licenças por fonte está em [docs/FONTES.md](docs/FONTES.md). Onde diz "por confirmar", os dados não são republicados.

Nota sobre a GPL-3.0: o `rgllm/awesome-portugal-data` é GPL-3.0. Este projeto só o referencia por link e não copia o seu conteúdo.
