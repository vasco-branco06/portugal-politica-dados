# Datasets publicados

Ainda não há datasets publicados. Quando existirem, cada um terá aqui um cartão com:

- nome e descrição;
- colunas (ver `docs/DICIONARIO_DADOS.md`);
- fonte, licença e como citar;
- data da última atualização;
- limitações conhecidas.

Destino previsto: Hugging Face (gratuito), com o código e a documentação neste repositório.
